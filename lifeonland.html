Life on Land is a responsive website built by a four-person team for the Web Design and Development module (4COSC011W). The project covered the end-to-end design and development lifecycle: from concept and visual identity all the way through to a fully functioning multi-page web application.

My specific contributions were the Feedback system and Team page, along with supporting the overall visual identity and navigation design. The site uses a dark, nature-themed aesthetic with rich imagery, structured typography, and a validated interactive feedback form.

SDG Connection: The project theme tied into UN Sustainable Development Goal 15 (Life on Land), using web design as a tool to raise awareness of biodiversity, conservation, and the natural environment.

The Team

Collaboration and ownership

My Contribution

The pages I built

Within the team structure I focused on two key sections: the Feedback system and the Team page. Both required careful attention to interaction design, form validation, and visual consistency with the established site template.

Feedback System
Designed and developed a validated feedback form with client-side JavaScript validation. The form includes field validation for name, email, and message fields, with real-time error feedback and success confirmation, following structured web design practices.

Built a team showcase page presenting all four contributors with consistent card layout, hover states, and integration with the site-wide navigation template.

Reflections

What I took from this project

01
Consistency is a team sport. When four people are building the same site, the only way to maintain a cohesive visual identity is through clearly documented standards. Templates, color variables, and shared typography rules are not optional, they are the product.
02
Form design has more depth than it appears. A validated feedback form sounds simple, but getting the error states, success confirmation, and field interaction logic right took real iteration. Good form UX is invisible when done well.
03
Working within constraints builds discipline. Pure HTML, CSS, and JavaScript without any frameworks forced me to understand the fundamentals deeply. Those fundamentals now make me a better designer because I know what is possible and what is costly to build.
